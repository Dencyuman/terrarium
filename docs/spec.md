# Terrarium Web — 現行仕様と移植状況

更新日: 2026-09-18。Web版v2の実装を記載する。旧Godot版の要件書・実装はGitコミット `5d3e248` に保存されている。

## 目的と状態

AIの住人が暮らす小さな世界を観察する社会シミュレーション。身体、性格、経験、他者との関係から行動を選び、会話や世代の変化を観察する。

現在は公開リポジトリで開発するWeb版のプロトタイプ。ローカルで観察・AI判断・保存を利用できる。旧版の全機能の移植と長期バランス調整は未完了。公開サーバーは運用していない。

## 世界と時間

| 項目 | 現在の仕様 |
| --- | --- |
| 地形 | 草地・水・森・岩。シードで生成 |
| 既定サイズ | 20 × 20マス |
| 初期人口 | UIで10 / 20 / 30 / 40人。既定20人 |
| 時間 | 1日30 tick、1 tickは世界内の48分 |
| 行動数 | デモ・Jevは1人1行動 / tick。Luna従来方式は最大5行動 / tick |
| 人口上限 | 既定100人 |
| 老衰 | 既定60日齢から |
| 天気 | 晴れ・曇り・雨。描画のみで物理・AI判断には影響しない |

同じシードで初期配置と地形を再現する。AIの選択まで毎回同じになる保証はない。選択済みの行動、世界状態、乱数状態が同じ場合、エンジンの結果は同じになる。

## 住人

住人は名前、性別、年齢、世代、親、位置、体力、満腹度、元気、食料、性格、繁殖欲求、攻撃衝動、有向の関係、記憶、認知状態を持つ。

- `health`: 体力。0で死亡。
- `hunger`: 内部名に反して、0が飢餓・100が満腹。
- `stamina`: 元気。行動コストと休息によって増減。
- 初期値: 体力100、満腹度45〜84、元気75〜99、年齢2日、繁殖欲求20、所持上限3。
- 初期の名前・性別・性格は `data/names.json` を参照。画面ではカタカナ / ローマ字で表示。
- 視界は周囲3マス。入力は本人の身体・認知・視界・記憶に限定する。

繁殖には隣接する異性の成人と、行動する本人の元気20以上などの条件がある。成功率は既定50%。条件を満たすだけで必ず行動・出生するわけではない。生まれた子は次のtickから行動する。

## 11種類の行動

| 内部名 | 表示・役割 |
| --- | --- |
| `wait` | ひと休み。元気を回復 |
| `move` | 歩く |
| `take` | 食料を拾う |
| `eat` | 食べる |
| `give` | 食料を分ける |
| `attack` | 攻撃する |
| `embrace` | 寄り添う |
| `look` | 遠くを眺める |
| `reproduce_with` | 命をつなぐ |
| `speak` | 話す |
| `teach` | 語り継ぐ |

候補は方向や相手も含む具体的な行動。候補数は「11種類」とは異なり、周囲の状態で変わる。列挙時と実行時に物理条件を検証し、先に他者が移動・死亡・拾得した場合は失敗し得る。

## 判断と言葉

- **デモ**: ブラウザ内のルールで行動と例文を選ぶ。API利用なし。
- **Jev**: 個体ごとに候補の確率と再考の必要性を取得。世界あたり最大20並列。
- **Lunaの熟考**: 必要時に目標・信念・優先事項・計画を非同期生成。行動を直接実行しない。
- **発話・教育**: Jevが選んだ種類と宛先を固定し、Lunaが本文を生成。そのtick内で完了を待つ。
- **Luna従来方式**: 生成LLMが最大5行動をまとめて提案する比較用モード。

OpenAIキーがないJev世界では、熟考・発話・教育を無効にする。言語生成の失敗を例文で補完しない。詳細は [認知処理](jev-cognition-design.md)。

| 項目 | Web版 |

| 住人の初期値・性格・配置の編集 | 未移植 |
| 世界サイズ・1日のtick数の編集UI | 未移植 |
| 食料生成率・行動コストの編集UI | 未移植 |
| 地形の手描き編集 | 未移植 |
| 初期条件を保存し、複数の実行へ使い回す旧版の管理画面 | 未移植 |

| 関係・家系・年代記・直近履歴の観察 | 実装済み |
| 旧Godot SQLite DBの自動読み込み | 未実装 |

内部の初期値は `src/simulation/world.ts` の `DEFAULT_CONFIG` / `makeAgent` が定義する。`data/config.json` から読むのは `costs` の数値項目で、旧版の `world`・`agents`・`llm` 設定や `data/config.local.json` の世界設定はWeb版へ自動適用しない。

## 進行と保存

世界はブラウザが要求したときだけ進む。再生停止、設定画面、履歴表示、タブ非表示では自動tick要求を止める。既に開始した要求は完了し得る。次の要求を重ねず、APIの遅延分を後からまとめて進める処理もない。

履歴は世界の分岐編集ではなく過去の観察。JSON書き出しは現在の世界状態を保存し、読み込みでは新しいIDのデモを作る。AIサーバーの世界を復元する機能ではない。

## 既知の課題

- 元気が低いまま推移し、生殖候補が出ず人口が増えにくいケースがある。繁殖欲求が100でも元気などの物理条件は省略されない。
- 発話・教育が選ばれたtickは、その文章生成が全体の進行を遅らせる。現在は同期方式を採用している。
- 熟考結果は形式・参照・古さを検証するが、自然言語の目標や信念の内容が常に妥当になる保証はない。
- 日次tick上限は料金の金額上限ではない。住人数・記憶・発話量で利用量は変わる。
