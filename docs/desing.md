# Terrarium Web — 画面・ビジュアル・操作

更新日: 2026-09-18。ファイル名は既存リンクとの互換性のため `desing.md` のまま維持する。旧Godot版のビジュアル構想はGitコミット `5d3e248` に残る。

## 表現の方針

小さな世界を眺める観察室。Canvas 2Dで地形・木・水・住人を手続き的に描き、立体的な箱庭として見せる。Reactが周囲の操作画面を担当する。Godotのシーンや購入スプライトは使っていない。

- 地形は草地・水・森・岩。
- 水面や木々、住人にアニメーションを付ける。
- 住人の選択・名前・会話・関係線で、誰が何をしているかを示す。
- 時間と天気に合わせて背景・照明・文字色を変える。
- 没入表示で周囲の情報量を減らせる。

## 画面の構成

| 領域 | 内容 |
| --- | --- |
| 上部 | 世界名、表示言語、観察画面の切り替え、設定 |
| 住人一覧 | 生存する住人、名前検索、個体の選択 |
| 世界 | ジオラマ、名前、発話、関係線、拡大・移動 |
| 個体詳細 | 身体、目標、選択確率、関係、記憶 |
| 関係・家系 | 関係のつながりと親子の系譜 |
| 年代記 | 世界で起きた出来事 |
| 下部 | 日時、人口、再生・停止、速度、履歴、推定API料金 |
| 設定 | 言語、天気、AI接続状態、合言葉、世界作成・切替、JSON入出力 |

年代記は観察者が見る情報。個体のAIへそのまま渡すものではない。デモの選択傾向はJevの実測確率と区別して表示する。

## 操作

- 住人をクリックして詳細を開く。
- 世界をドラッグして移動し、ホイールや拡大操作でズームする。
- スペースキーで再生・停止する。入力中・設定画面内ではショートカットを適用しない。
- Escapeで没入表示と選択を解除する。
- 履歴を選んで過去の状態を観察する。表示中に世界を自動進行させない。
- 右上の設定から世界を作成・切り替える。

速度設定はtick要求の間隔を変更する。API処理中は次の要求を出さないので、倍速設定がそのまま実時間の倍速になるとは限らない。

## 時刻と天気

時刻は世界のtickから計算する。既定は1日30 tick。ラベルの区分は以下の通り。

| 時刻 | 表示 |
| --- | --- |
| 00:00〜04:59 | 夜 |
| 05:00〜08:59 | 朝 |
| 09:00〜15:59 | 昼 |
| 16:00〜19:59 | 夕方 |
| 20:00〜23:59 | 夜 |

背景色や照明は区分で突然切り替えず、複数の時刻の色を補間する。設定する天気は **晴れ・曇り・雨** の3種類で、朝昼夕夜とは独立する。晴れでも世界内の夜には暗くなる。

天気はブラウザに保存する表示設定。資源再生や住人の身体・判断を変える機能ではない。

実装: `src/game/atmosphere.ts`、`src/game/renderer.ts`、`src/components/WorldCanvas.tsx`。

## 言語と名前

日本語・英語の表示を切り替え、ブラウザに選択を保存する。

- 住人名: 「モミ・シイ・ムクゲ」 / 「Momi・Shii・Mukuge」のように読みやすく表示。
- 検索: 元の漢字、カタカナ、ローマ字に対応。
- ID・保存された名前・関係・記憶の同一性は維持。
- メニュー、定型イベント、デモの言葉は翻訳辞書で切り替え、翻訳APIは呼ばない。
- AIが新しく生成する文章には現在の言語を指定する。過去のAI文章や利用者が付けた世界名は自動翻訳しない。

実装: `src/i18n/`。保存された世界を描画用に変換し、元データを書き換えない。

## 音と素材

環境音は利用者の操作で有効にする。外部の音楽サービスには接続しない。

フォントはCormorant Garamond、Noto Sans JP、IBM Plex Mono、アイコンはLucide。npm依存から配信し、実行時にフォントCDNへアクセスしない。
