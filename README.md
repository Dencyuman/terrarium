# Terrarium

**Terrarium** は、LLM が動かすエージェントの小さな社会を観察するデスクトップシミュレーションです。食料を探す、移動する、会話する、助け合う、争う、記憶を伝えるといった行動が、個体の状態と周囲の状況に応じて進みます。

プレイヤーが社会のルールや物語を決めるゲームではありません。ハーネスは主に世界の物理条件を処理し、行動の意味や伝承の真偽はエージェントに委ねます。

## 特徴

- 地形、食料、個体の状態を持つグリッド世界
- Ollama、Anthropic、Gemini を使ったエージェントの意思決定
- 個体の誕生・加齢・死亡、関係性、家系の記録
- 発話、食料の受け渡し、攻撃、抱擁、教育などの行動
- エージェントの行動やイベントを追う世界ビュー、関係性グラフ、家系図、イベント年代記
- テラリウムの作成・編集と、過去 run の記録・閲覧

`teach`（教育）では、隣接する生存エージェントにテキストを伝えます。受け手には話し手と日時が付いた二次記憶として残ります。内容の真偽は検査されず、伝達時に自動で変質することもありません。

## 必要なもの

- Godot **4.4 以降**のデスクトップ版
- 以下のいずれかの LLM 接続
  - Ollama をローカルで起動
  - Anthropic API キー
  - Gemini API キー

SQLite 用の Godot プラグインはリポジトリに含まれています。

## 起動

1. リポジトリを取得します。

   ```sh
   git clone https://github.com/Dencyuman/terrarium.git
   cd terrarium
   ```

2. Godot でこのフォルダーをプロジェクトとしてインポートします。
3. エディターから実行します。起動シーンはテラリウム一覧です。

コマンドラインから起動する場合は、Godot 実行ファイルを使って次のように実行できます。

```sh
godot --path .
```

## LLM の設定

既定では `data/config.json` の Ollama 設定を使います。既定の接続先は `http://localhost:11434`、モデル名は `gemma4:e4b` です。Ollama を起動し、設定したモデルを利用できる状態にしてください。

個人用の設定は、リポジトリ直下の `data/config.local.json` に JSON で記述します。このファイルは Git 管理対象外です。`config.json` に対する部分上書きとして読み込まれます。

Anthropic を使う例:

```json
{
  "llm": {
    "provider": "anthropic",
    "anthropic_api_key": "YOUR_ANTHROPIC_API_KEY"
  }
}
```

Gemini を使う場合は `provider` を `gemini` にし、`gemini_api_key` を設定します。モデル名を変える場合は、それぞれ `anthropic_model` または `gemini_model` も指定できます。Ollama の接続先やモデルを変える場合は `provider: "ollama"`、`endpoint`、`model` を設定してください。

設定ファイルの主な項目:

- `llm`: 接続先、モデル、温度、並列数、タイムアウト
- `world`: マップサイズ、乱数シード、1 日あたりの tick 数、視界
- `agents`: 初期個体数、所持品容量、初期状態
- `costs`: 行動に必要な空腹度・元気度、ライフサイクルや衝動の値
- `resources`: 食料の初期発生・再生
- `relations`: 行動に応じた好感度・信頼度の変化

実験条件はテラリウムごとに保存できます。LLM 接続情報はテラリウム設定から分離され、ランタイム設定として読み込まれます。

## 使い方

1. 一覧からテラリウムを起動するか、「新規作成」からマップ、キャスト、各種パラメーターを設定します。
2. シミュレーション画面で再生・一時停止し、エージェントの状態やログを観察します。
3. タブを切り替えて、関係性、家系、イベント年代記を確認します。
4. 一覧の「過去 run」から保存された run の詳細やマップ再生を開きます。

シミュレーションは tick 単位で進みます。各 tick でエージェントに観測情報を渡し、LLM の応答を行動として処理します。接続状態やトークン数、推定 API コストは画面に表示されます。ローカルモデルの費用表示はトークン数を示します。

## 行動とシミュレーションの考え方

エージェントが選べる主な行動は、移動、食料の取得・摂取、発話、受け渡し、攻撃、抱擁、視線による調査、生殖、教育、待機です。実行できるかどうかは隣接、地形、対象の状態、所持品、元気度などの物理条件で決まります。

ハーネスは発話や教育の内容が正しいかを判定しません。受け手が伝承を信じるか、関係をどう捉えるかもエージェント側の応答に委ねられています。

## データの保存

- テラリウム、run、イベント、シミュレーション状態は SQLite に保存されます。
- データベースは Godot のユーザーデータ領域にある `user://terrarium.db` です。リポジトリ内には作成されません。
- run はテラリウムごとに記録され、実行中の run は次回起動時に復元されます。
- `data/config.local.json` は個人用設定です。API キーをコミットしないでください。

## ディレクトリ構成

```text
terrarium/
├── addons/godot-sqlite/  SQLite 用 Godot プラグイン
├── assets/               テーマなどのアセット
├── data/                 既定設定、名前データ、個人用設定
├── docs/                 要件・デザイン資料
├── scenes/               Godot シーン
└── scripts/
    ├── core/             世界、エージェント、スケジューラー、永続化
    ├── llm/              LLM クライアント、プロンプト、応答解析
    └── ui/               一覧、編集画面、可視化ビュー
```
