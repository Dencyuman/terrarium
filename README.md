# Terrarium

**小さな命の、終わらない物語。**

AIが暮らす森を、ブラウザから観察する社会シミュレーション。水面の揺らぎ、木々の呼吸、住人たちの会話や出会いを、立体的な箱庭で眺められます。

Godot版を **React / TypeScript / Canvas / Cloudflare Workers** で作り直しています。Godotは不要で、ローカルではNode.jsの開発サーバーから利用できます。

**[ローカルの観察室をひらく](http://127.0.0.1:5173/)**（先に下記の起動手順を実行）

現在はローカルで開発しています。Cloudflareの公開環境は削除済みです。

## 現在の状態

Web版の観察・AI判断・保存は動作しますが、旧版の全機能の移植は完了していません。

- 世界作成で変更できるのは **名前・地形シード・初期人口（10 / 20 / 30 / 40人）・知能モード** です。
- **初期パラメータ編集は未移植**です。旧版にあった住人の性格・初期値、世界や食料・行動コストの編集、地形の手描き編集は、現在の画面ではできません。
- 元気が低い状態で推移し、生殖に必要な元気を満たせず人口が増えにくいケースを確認しています。長期のバランス調整は未完了です。
- 発話・教育の文章生成は **同期処理** です。そのtickの全員の判断と言葉がそろうまで進みません。目標などの熟考は非同期です。

## できること

- 既定20人から始まる世界。食料、体力、元気、性格、関係、記憶、出生、世代、死亡
- **11行動**: 移動、拾得、摂食、受け渡し、攻撃、抱擁、観察、生殖、発話、教育、休息
- **Jev / System 1**: 実行可能な行動から選択し、再考が必要かを同時に判断
- **生成LLM / System 2**: 必要時に裏で熟考。目標・信念・計画を更新し、現在の行動を止めない
- Jevが発話・教育を選んだときだけ、その言葉を生成
- 個体の選択確率、身体、目標、関係、記憶を表示
- 関係性グラフ、家系、年代記、時間を戻して観察する履歴
- 拡大・移動、時刻に連動する朝・昼・夕方・夜の背景、晴れ・曇り・雨の設定、名前・関係線、没入モード、控えめな環境音
- デモのブラウザ内保存、AI世界のサーバー側保存、世界のJSON書き出し・読み込み
- APIキーがなくても試せる **無料のローカルデモ**。デモの選択傾向はAIの回答ではありません

## 起動

Node.js 24以降を用意します。

```sh
npm install
npm run dev
```

[ローカルの観察室](http://127.0.0.1:5173) を開きます。最初はローカルデモが動きます。スペースキーで再生・停止、住人をクリックして詳細を開きます。画面右上の設定から世界の作成・切替もできます。

APIとDurable Objectもローカルで動作します。Cloudflareへのデプロイは不要です。AIモードでのTypeSafe / OpenAI呼び出しには各サービスのAPIを使います。

### 表示言語と住人名

右上の言語メニュー、または「観察の設定」から日本語・英語を切り替えられます。設定はこのブラウザに保存します。

住人名は日本語で「モミ・シイ・ムクゲ」、英語で「Momi・Shii・Mukuge」のように表示します。既存の保存データにも適用され、住人のID・関係・記憶は維持します。名前検索は元の漢字名・カタカナ・ローマ字に対応しています。

メニュー、行動候補、出来事、デモの会話は言語を切り替えるだけで表示が変わります。翻訳用のAPI呼び出しはありません。新しくAIが生成する会話や目標も選択中の言語を使いますが、過去のAI文章と自分で付けた世界名は元の内容を保持します。

### 時間と天気

既定では **1日30 tick**、1 tickは世界内の48分です。朝・昼・夕方・夜の背景は世界の時刻に合わせて徐々に変化します。晴れ・曇り・雨は別の表示設定で、食料や住人の行動には影響しません。

再生速度はtick要求の間隔を変えます。AI処理中に次のtickを重ねないため、実際の進行速度はAPIの応答時間にも左右されます。停止・タブ非表示にする前に送った要求は完了することがあります。

### AIの接続

`.dev.vars.example` を `.dev.vars` にコピーして設定します。

```dotenv
TYPESAFE_API_KEY="TypeSafeのキー"
OPENAI_API_KEY="OpenAIのキー"
```

旧版の `data/config.local.json` に `llm.typesafe_api_key` / `llm.openai_api_key` がある場合、値を画面に表示せず `.dev.vars` へコピーできます。同じ名前の既存キーは上書きします。Geminiのキーや世界設定は移行しません。

```sh
npm run secrets:local
```

開発サーバーを再起動し、「新しい世界」から知能を選びます。

| モード           | 実行場所 | 判断                                       |
| ---------------- | -------- | ------------------------------------------ |
| 観察デモ         | ブラウザ | 明示的な行動ルール。API呼び出しなし        |
| Jev              | Workers  | 1個体1リクエスト、最大20並列。1行動 / tick |
| Luna（従来方式） | Workers  | 生成LLMが最大5行動 / tickを選択            |

Jevキーだけでも即時行動は動きます。OpenAI APIキー未設定時は、熟考・発話・教育が無効であることを設定・作成画面に表示します。言語生成に失敗した場合はwaitとして記録し、プリセットの言葉に置き換えません。

生成モデルは **GPT-5.6 Luna**（`OPENAI_MODEL=gpt-5.6-luna`）。OpenAI Responses APIの構造化出力を使い、発言・熟考・従来方式の行動生成を担当します。推論設定は `none`、通常処理（`service_tier=default`）、生成上限は900トークンです。個体の観測と記憶だけを渡す境界は共通です。

### 公開リポジトリと秘密情報

実際のAPIキーは `.dev.vars` に置き、公開環境ではWranglerのSecretに設定します。`VITE_` で始まる変数や `src/`、`wrangler.jsonc`、共有用JSONには書かないでください。

`.dev.vars*`、`.env*`、`data/config.local.json`、`.wrangler/`、`runs/`、SQLiteデータ、`dist/` はGit管理外です。空の `.dev.vars.example` だけを共有します。ビルド時に `dist/terrarium/.dev.vars` が作られることがあるため、`dist/` を手動で公開・添付しないでください。世界のJSONには会話や記憶が入るので、共有前に内容を確認してください。

### API料金の表示

料金表示はJevとLunaの公表単価による概算です。Lunaは100万トークンあたり通常入力$0.20、キャッシュ入力$0.02、キャッシュ書き込み$0.25、出力$1.20。入力が272,000トークンを超える場合の倍率も反映します。APIが返したキャッシュ利用量と、推論を含む出力トークン数を使用します。他の生成モデルを指定した場合は価格を推測せず「一部未集計」と表示します。過去の利用額は保存時のまま保持します。[OpenAI公式料金](https://developers.openai.com/api/docs/pricing)

## Cloudflareへ配備

将来配備する場合は、アカウント名・アカウントID・環境を所有者に確認してから実行します。ログイン済みのアカウントを配備先とみなさないでください。

1つのWorkerに画面とAPIをまとめ、世界ごとにSQLite付きDurable Objectを使います。D1、R2、Queues、外部DB、常駐VMは不要です。

```sh
npx wrangler login
export CLOUDFLARE_ACCOUNT_ID="確認済みの配備先アカウントID"
npm run deploy
npx wrangler secret put TYPESAFE_API_KEY
npx wrangler secret put OPENAI_API_KEY
npx wrangler secret put ADMIN_TOKEN
```

`ADMIN_TOKEN` は任意の十分長いランダムな文字列にします。公開環境でAIの実行を無認証で開放しないための合言葉です。観察室の設定に入力するとクラウドの世界を操作できます。キーはサーバー側のみで使用し、ブラウザ配信物に含めません。

合言葉を設定していない公開環境では、ローカルデモだけが利用可能です。localhostでの開発時のみ合言葉なしでAPIを使えます。

### 費用と停止の仕組み

[Workers Paid](https://developers.cloudflare.com/workers/platform/pricing/) は **月$5からの従量プラン**です。完全固定料金ではありません。静的アセット配信は無料枠ではなく無料扱いで、シミュレーションにはWorkerとDurable Objectの利用枠が適用されます。

- 世界はブラウザからtickを要求したときだけ進行します。タブが非表示・閉じた状態ではtick要求を送りません。
- サーバーに常時タイマー、1秒ごとのalarm、永続WebSocketを置いていません。
- 1個体ごとではなく、1 tickで保存。最新状態と直近120 tickの履歴を保持します。大きな世界は512 KiBずつ分割保存します。履歴の一括取得は最新側から8 MiBまで、ブラウザ内の巻き戻しも容量を制限します。
- 個体の長期記憶とイベントはSQLiteへ保存。長期間の運用ではこれらのデータ量も管理対象です。
- `MAX_AI_TICKS_PER_DAY`（既定500）で、デプロイ全体のAI tick要求に日次上限を設けます。失敗・競合した要求も保守的にカウントします。
- 世界ごとの同時思考は2件、個体の再考には5 tickの間隔。HTTPにはタイムアウトと再試行上限があります。
- `wrangler.jsonc` に1呼び出しのCPU上限を設定しています。

**TypeSafe / OpenAIのAPI代はCloudflare料金とは別**です。画面には役割別の利用量から合計した推定API代を表示します。20人のJev判断を1 tick動かした開発時の計測では、20件成功・約1.08秒・入力62,321トークン・推定$0.00262でした。状態・記憶の量で変わります。会話のあるtickでは文章生成の待ち時間が加わります。

## 保存と互換性

- デモ: IndexedDBに世界を保存。ブラウザの保存データを消すと失われるため、必要な世界はJSONで書き出せます。
- AI: Durable ObjectのSQLiteと保存APIで管理。ローカル開発時は `.wrangler/` 配下に保存され、ブラウザ側にも最後に受信した状態を保存します。公開環境とは別のデータです。
- 再開時は未完了の熟考を再実行せず、次の判断で必要性を再評価します。
- JSONの読み込みはWeb版v2用で、**新しいIDのローカルデモとして読み込みます**。AIサーバーへの復元・複製ではありません。旧GodotのSQLite DBを自動変換する機能はありません。旧版はGit履歴の `5d3e248` から参照できます。
- 過去のGodot用DBや、Git管理外のローカル実験ログは削除しません。

## 開発

```sh
npm test          # 世界、物理条件、知覚の隔離、API応答、非同期認知
npm run build     # 型チェック + クライアント/Workerのビルド
npm run preview   # ビルド済み環境をローカルで確認
```

```text
src/
  i18n/           日英の文言・住人名・保存済みの表示変換
  simulation/     描画・サーバーから独立した世界、物理、認知
  game/           Canvasによるジオラマとアニメーション
  components/     観察画面、個体詳細、関係・家系
worker/           Cloudflare API、永続化、Jev・生成LLM
public/           共通のシンボル
tests/            意味のある境界・不変条件の検証
tools/            ローカル設定移行
```

描画素材はこのプロジェクトの手続き的な描画で統一しています。フォントはCormorant Garamond、Noto Sans JP、IBM Plex Mono（SIL Open Font License）、アイコンはLucide（ISC）を利用し、実行時に外部CDNへ依存しません。
